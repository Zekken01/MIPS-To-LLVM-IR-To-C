## Validation limits

This is a successfully linked native translated-code library with the current host dispatcher and runtime glue. It is **not yet a bootable or complete PS2 game**.

The full game was not executed through `ee_game_run`. The runtime is still incomplete for a real title: BIOS/IOP services, GS, DMA, TLB/MMIO devices, interrupts, and other console integration remain necessary. The flat memory/runtime prototype is not a complete Emotion Engine machine model.

The project's in-tree `object_emitter::emit_object()` remains a stub. Per-function host objects in this validation were generated by the external llvmlite validation tool, then persisted and linked by `tools/link_native_objects.py`.

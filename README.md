# MIPS To LLVM IR To C

PS2 Emotion Engine (R5900) recompiler research and implementation.

This repository is being initialized from the latest recoverable source snapshot. See `RECOVERY_PROVENANCE.md`, `WORK_LOG.md`, `TEST_RESULTS.md`, and `RESUME.md` for the source lineage and verified baseline.

The first recovery milestone is the MMI / secondary HI1-LO1 transfer implementation and its compiled LLVM JIT regression. The in-project object emitter remains a stub; this is not yet a runnable static recompiler.
